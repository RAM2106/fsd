# React project used by Experiments 5(b), 6, 7, 8, 9, 10 and 13(b)

This is one shared Vite React project. Each experiment has its own `App.jsx` in the corresponding experiment folder. To run one, copy that file over `src/App.jsx`. For Experiment 7(b), also copy its `App.css` to `src/App.css`.

## First-time setup

```bash
cd 06-react-basics
npm install
npm run dev
```

Open the local URL printed in the terminal (usually `http://localhost:5173/`).

## Select an experiment

Examples:
- Experiment 6(a): copy `06-react-basics/src/App.jsx` (default starter).
- Experiment 6(b): copy `06-react-basics/6b-jsx/App.jsx` to `src/App.jsx`.
- Experiment 6(c): copy `06-react-basics/6c-components/App.jsx` to `src/App.jsx`.

For other React programs, see their experiment README and copy the listed file from that folder to `src/App.jsx`.

Stop Vite with `Ctrl + C`.
