# Experiment 7 – React Props, State, Styling and Events

Run the shared Vite project: follow `06-react-basics/README.md`. Copy the relevant file to `06-react-basics/src/App.jsx`.

## 7(a) Props and state
File: `7a-props-state/App.jsx`. Shows a `Greeting` child receiving `name` as a prop and a counter managed by `useState()`. Click Increase to increment the count.

## 7(b) CSS styling
Files: `7b-css-styling/App.jsx` and `7b-css-styling/App.css`. Copy both into the Vite project's `src/` folder. Displays a light-blue styled box.

## 7(c) Events
File: `7c-events/App.jsx`. Click the button to display the `Button Clicked` alert.

**Key points:** Props pass data; state stores changing values; `className` applies CSS classes; `onClick` handles click events.
