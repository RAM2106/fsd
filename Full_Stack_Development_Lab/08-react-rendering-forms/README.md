# Experiment 8 – Conditional Rendering, Lists and Forms

Run the shared Vite project: follow `06-react-basics/README.md`. Copy the selected `App.jsx` into `06-react-basics/src/App.jsx`.

## 8(a) Conditional rendering
File: `8a-conditional-rendering/App.jsx`. `isLoggedIn` is true, so the page displays `Welcome User`. Change it to false to see the other branch.

## 8(b) Rendering lists
File: `8b-render-lists/App.jsx`. Uses `map()` to display Ram, Ravi and Kiran.

## 8(c) React forms
File: `8c-react-forms/App.jsx`. Enter a name and select a course; the values appear below the fields.

**Key points:** Conditional rendering uses a condition; `map()` displays array items; `useState()` and `onChange` manage form values.
